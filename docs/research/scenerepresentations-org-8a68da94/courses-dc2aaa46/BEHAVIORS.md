# Teaching Page Behaviors

- Six course cards are ordinary links; there is no filter, pagination, tab, or scroll-triggered state.
- Three external Advances links carry a blue arrow prefix; internal inverse-graphics cards do not.
- Card hover follows the shared 333ms → 100ms border/background/shadow transition.
- The page background uses a 16×16px radial dot pattern.
- Header active item is Teaching. Theme toggle is shared.
- Responsive grid: four columns at 1440px, two at 768px, one at 390px.
